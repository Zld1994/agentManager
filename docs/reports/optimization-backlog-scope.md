## 当前能力基线

`agentManager` 是一个 Python 3.10+ AI Agent 编排控制面原型。核心架构：

- **引擎层**: DAG 引擎、调度器、状态机、检查点管理、事件总线
- **存储层**: PostgreSQL 持久化状态、S3 对象存储、Qdrant 向量搜索
- **运行时**: 任务执行器、工作流协调器、沙箱执行
- **API**: FastAPI REST API + OpenAPI 文档

## 本轮优化范围

本轮优化限定为**后端配置、API、角色/任务 JSON、模板库、安装脚本和文档**。不新增独立 Web 前端。
